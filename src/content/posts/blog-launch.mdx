折腾了几天，博客终于上线了。

## 为什么选 Astro

之前用过 Hexo、Hugo，也试过 WordPress。Hexo 主题生态偏 geek，Hugo 的模板语法让人头疼，WordPress 又太重。Astro 的好处是——它就是一个现代的、Islands 架构的静态站点框架，你写什么就是什么，不强行塞给你一套主题审美。

```ts
export default defineConfig({
  site: 'https://username.github.io',
  integrations: [mdx(), sitemap()],
});
```

配置极简，构建飞快，默认输出纯静态 HTML，部署到 GitHub Pages 几乎零成本。

## 内容结构

我把内容分成两类：

- **开发记录**：技术笔记、踩坑、项目复盘——你正在看的这篇就是
- **日常图文**：照片 + 短文，类似生活记录

两者共享同一套排版基线，但版式自适应。图文帖支持单图和多图画廊。

## 设计取向

避开了技术博客常见的全 sans + 等宽 + 深色优先的套路。这次用 Fraunces 衬线做标题，暖白底，单一灰玫瑰点缀色。目标是看起来像一个"会写字的人"的博客，而不是一个"会写代码的人"的博客。

> 质感来自克制，不是堆砌。

下一步打算把评论区接上 Twikoo，再把 RSS 配好。这个博客会慢慢长起来。
